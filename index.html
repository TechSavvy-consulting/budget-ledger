Budget Ledger Help

Simple home ledger workflow
1. Set up Create users, name books, add accounts, and set budget targets.
2. Record activity Add income, expenses, transfers, and recurring transactions as they happen.
3. Review Use reports, account registers, and reconcile to find missing or uncleared items.
4. Protect data Change your password, export backups, and log out when finished.

Home

Use Home for fast entry and a quick read on budget categories. Quick Add is best for simple income, expenses, and transfers that do not need notes or splits.

  • Pick the month at the top before reviewing totals.
  • Use Quick Add for day-to-day entries.
  • Watch Budget Categories for overspending signals.

Transactions

Transactions are the main ledger. Use the date range fields to narrow what you are reviewing, and use Add Recurring for bills, paychecks, and transfers that repeat.

  • Expenses debit the selected account.
  • Income increases the selected account.
  • Transfers move money between two accounts.

Budgets

Create targets for categories you want to track. Budget periods can be weekly, monthly, or yearly, and reports compare actual spending against those targets.

  • Use clear category names like Grocery, Housing, Fuel, or Insurance.
  • Edit a target when your plan changes.
  • Delete targets you no longer track.

Accounts & Assets

Add checking, savings, credit cards, loans, vehicles, and other assets or liabilities. The register shows running account activity inside the selected date range.

  • Check In Bank when a transaction appears at your bank.
  • Enter statement date and balance in Reconcile.
  • Reconcile only when the difference reaches $0.00.

Reports

Reports summarize income, spending, remaining cash, net worth, daily expense flow, upcoming cash flow, top spending, and account balances for the selected period.

  • Switch Week, Month, or Year at the top.
  • Use Daily Expense Flow to spot unusual spending days.
  • Use Upcoming Cash Flow to see what is coming next.

Settings

Admins can add users, assign roles, edit books, delete books, and manage demo data. Standard users can change appearance, change their own password, and import or export their own data.

  • Admins should keep at least one admin login active.
  • Users cannot see or edit other users' books.
  • Use Log Out when sharing a computer.

Import & Export

Export JSON for a restorable backup, CSV for transaction review, or Spreadsheet for workbook-style reporting. Imports replace the relevant data, so export first when you are unsure.

  • Admins export the full app state.
  • Users export only their own book data.
  • Keep periodic JSON backups outside the app.
